# 戴夫工坊

主菜单的独立经营模式。准备阶段全厂停机，只允许施工，阳光、生产、运输与电路计时均冻结；先搭建生产线，再主动开启袭击，所有机器从保留的进度恢复运行；胜利后保留整个基地，准备好才开启下一波。支持五类前线弹药、残骸回收及独立工厂地图，不承诺图灵完备。

## 玩家操作

- 点击右侧“建造图册”或按 `B` 打开图文展板，按生产、物流、电路分类查找机器。卡片直接显示与地图一致的大图、用途、价格及解锁波次，悬停仍可查看详细参数。锁定机器可查看但不能选用；阳光不足时可先选择，预览标红且放置不扣费。
- 图册沿用模态输入拦截，打开时自动暂停；返回或 `Esc` 关闭后恢复原手动暂停状态及倍速。帮助与重开确认也支持 `Esc` 关闭，死亡选择和坏档提示保留明确处理入口。图册选择只切换建造工具，实际放下每台机器时才由正式建造事务扣费。
- 侧栏保留本次工坊界面的最近六种选择（新界面先列常用机器），不写入经营存档。选择建造物后可连续轻点空格放置；资源不足标红且不扣费。`R` 优先旋转鼠标指向的现有机器（刚放下也可直接旋转）；建造时指向空地才旋转预览，同类后续放置沿用方向。每类机器分别记住方向，无格边出料的设备不旋转。`Esc` 或右键结束当前工具并清除选择，点击已有机器可直接选中并配置，无需先退出建造。
- 在建造按钮或已建机器上悬停可查看 tooltip：用途、输入输出、生产/输送速率、容量、当前库存与停机原因；暂停时也可阅读。
- 查看工具选中支持升级的机器后，可在右下角花阳光升级；前线点击一株普通/寒冰射手或西瓜/冰瓜，在顶部升级。这些对象独立保存三级等级，守住第 2/5 波开放二/三级；升二级花原建造价，升三级再花原价两倍。tooltip 与选中面板显示当前和下一级收益、费用及解锁条件。
- 射手升级提高冷却、索敌与射击动画的速度，单颗伤害和每颗弹丸耗一颗弹药的规则不变。机器升级保留库存、布线与生产周期完成比例；射手升级保留生命、冷却进度与在播前摇。运输带、分流器、装填口、回收入口和逻辑设备保持基础等级；仓库扩容不改变每行前线弹仓容量。
- 集光器提供全基地共享的阳光能源，育豆机生产实体豌豆，运输带沿箭头运输。装填口明确选择前线第 1–5 路与弹种，工厂格子的行不限制供货路线；射手有对应弹药且本行存在敌人时才发射。
- 分流器默认轮流向前方和右侧供货。A 接入信号后，高电平优先右侧，低电平优先前方；优先出口堵塞时可走另一出口。设置弹种筛选后，匹配类型只走右侧，其余只走前方；堵塞时等待，避免串料。弹药仓可设置收货弹种，切换时保留已有库存。装填口切换弹种后，只收取和装填匹配弹种；缓冲中的其他弹药保留，改回原类型或混合后继续运输。
- 接线先点击来源，再点击目标；工具条、光标和连线预览显示当前步骤。无效目标保留来源，成功后回到查看；按住 `Shift` 可保留来源连续连接，`Esc`/右键取消。A 控制生产/运输机器启停。与门、或门、记忆器和计数器支持 B 口。计数器只在 A 上升沿加一，B 清零优先于计数；达到设定值输出高电平，读档保留上一拍输入以防虚增。库存器读取 A 来源的实体库存，未接线时读取指定路线弹仓，两种方式均可选择单一物料或总库存；残骸只有机器来源有值。敌情器显式指定路线与敌人数阈值。定时器的 A 控制运行，未接线时持续运行；记忆器 A 置位、B 复位，复位优先。
- 暂停允许规划与建造。拆除工具用顶部文字、红框、目标叉与光标提示共同标识，显示退款和内部弹药损失；默认拆一台后退出，按住 `Shift` 才连续拆除。机器拆除返还建造和全部升级能源，仍受全基地储能上限约束，内部弹药丢弃。前线选择植物卡片后点击格子付费种植，左侧六列五行自由布阵，每格一株主植物，同时部署上限由格位决定。铲除不退款，默认铲一株后退出，Shift 连铲。植物被吃掉会失去该株升级与成长，补种从初始状态开始。
- 工厂和前线是同一基地的两个视图，切换不暂停袭击阶段的模拟，准备阶段始终停机。工厂右侧显示五行库存与敌情摘要；开战自动切到完整草坪，角色使用原版 reanim 的正常尺寸，可随时返回工厂调整。
- 机器解锁来自本模式守住的波次，新基地为 10×10，扩建宽高各增加两格，分别封顶 20 格。没有冒险植物库导入，也不向冒险发放奖励。
- 前线复用正式 `Board`、`PeaShooter` / `SnowPeaShooter`、`Zombie` 和 `Bullet`：阴影、射击/啃食/受伤/死亡动作、音效、命中与断肢粒子都走冒险已有流程。出怪与预告共用 `WorkshopRoster.h`，逐步加入橄榄球、巨人、急救员、震晶鼓手与适应头盔，保留各自真实能力；巨人首次登场整波只出一只。

- 守住第 3 波后，冷凝机将一颗普通豌豆与阳光加工成一颗寒冰弹；寒冰射手只吃寒冰弹，普通射手只吃普通弹。植物同时部署由前线可用格位限制。寒冰命中沿用正式子弹的减速、粒子、动画和阴影。
- 每路前线五弹种共用总容量。点击“弹药库存/配额”打开分配面板，增加一种配额从最大其他配额拨出，降低配额不销毁超额库存；首次种植该弹种植物且配额为零时自动拨出空间。装填口支持指定弹种或混合，残骸不会进入前线。
- 默认以清晰建造尺寸进入，缩到总览时省略机器上的细小数字；按住左键移动即可拖图（保留中键拖动），滚轮以鼠标为中心缩放，方向键在暂停时也能平移；“适应地图”和加减按钮固定在工具栏。格线始终独立绘制，悬停青框与选中金框跟随同一格位坐标。左键轻点在松开时提交格位操作，移动超过点击容差后只移动地图，建造、拆除与接线均不例外；拖出视口、取消工具或弹窗出现后不会补做点击。切换工厂/前线、重载、重试或重开清除遗留工具状态。悬停有方向的机器会标出出料目标，并区分地界、缺接收设备、弹种不兼容和缓存满。

## 扩展植物与回收

前线“植物图册 [B]”提供植物选择；机器和植物的未解锁卡片仅显示锁及所需波次，不显示名字、图片、费用或用途。坚果、高坚果和冰仓坚果不耗弹药；孢子培养机供给精英胆小菇，瓜果培育机供给西瓜投手，冷凝机在原料清空后可切换冰豌豆/冰瓜配方。切配方保留成品库存，输出仍使用原有输送规则。新设备沿用图册、旋转、升级、物流和电路接口。

“图解指南”与每张已解锁卡片上的“图解”按钮可重看用途、操作步骤与连接示例；选中机器或植物后点顶部指南会直接定位该条目。新基地先介绍最小供弹线；完成波次后，把新开放的机器和植物合并到一个暂停的分页弹窗，Esc 或“稍后查看”关闭后可随时重看。目录只包含已解锁内容，实线表达物料/资源去向，虚线标明 A/B 控制端口。

场景将可选 `guideSeenWave` 写在基地文档顶层，只记录已确认的新解锁提醒，不进入战斗检查点，也不决定真实解锁。旧档缺字段时从当前完成波数开始提醒；异常元数据使用同样默认，不让教程损坏导致基地无法载入。重开清零阅读进度；未确认的提醒随存档保留，重进后在准备阶段补弹。入口：`WorkshopGuide.h` 与 `WorkshopSceneGuide.cpp`。

图册图片按原比例居中；选择植物后，前线复用 `Board::CreatePlantingPreview` 的手持本体与半透明落点，不占格或写入存档。不可种植原因显示在底部状态栏，Esc、右键、切换视图或退出种植时清除预览。两种视图右上方都有倍速滑条；调速只修改选定倍率，暂停和准备阶段的停机规则保持有效。

冰瓜必须原位升级西瓜，继承已付费的攻速等级和剩余生命比例。精英胆小菇沿用本体射击成长：跨波和断供不清零，缺弹不发射也不成长，受惊清零；没有额外三级攻速购买。冰仓坚果的修复直接支付工坊阳光，可切手动/自动，准备阶段停止修复与能力计时。所有植物继续走原有 Animator、弹丸、受伤与死亡流程，工坊不新增动画帧事件。

真实敌方战斗死亡提交残骸队列，多个回收入口共享队列，不复制收益。入口 → 运输带/仓库 → 回收机，回收完成才获得阳光；每波全基地共用掉落上限，越线、清理存活对象、场景销毁和时间替换不计入。准备阶段队列与在途残骸保留，但入口、物流和加工都冻结。失败继续同时回退掉落计数和加工状态，避免重领。

植物费用、解锁、弹种以及敌方登场顺序集中在 `WorkshopRoster.h`；设备费用、材料成本、分级产速、回收收益和上限集中在 `Workshop.h/.cpp`。这些数值是首轮实现参数，实机平衡由主人后续统一测试。

## 独立存档与失败恢复

`GameInfoSaver::GetWorkshopSavePath()` 返回中央保存目录中的 `workshop.json`。文件拥有独立 `schemaVersion`，与 `PlayerInfo.json` 和关卡快照分离。修改、阶段切换、定期自动保存以及离开场景均经 `FileManager` 原子替换；不模拟离线生产。读取准备期存档或死亡继续不会启动生产，既有库存、布线和周期余时均保留到下一次手动开波。

存档保存基地、库存、生产/运输时钟、信号、前线、在途弹丸、敌人、波次与生成余量。开战前保存一份检查点；死亡状态也会保存，重进仍可选择：

- **继续经营**：恢复本次袭击开始前的基地，可重新规划后再挑战。该波开战后的施工与消耗一并回退。
- **重开基地**：经过确认，清空整个工坊的建设、资源、解锁和波次，从初始配置重新开始。
- **保存返回**：保留败局及检查点，稍后再选择。

工厂数据先在临时模型中验证，真实前线在新建 Board 中走正式关卡 schema 和对象恢复流程。坏档、未知版本、非法引用或恢复异常会停止整个场景并保护原文件，不继续运行或保存部分恢复的对象。开发期简化前线旧档保留基地；未完成袭击回到原开战检查点，再创建原生前线。

工厂 schema 3 使用固定 20 列存储跨度，保存独立宽高、全部物料库存、配方、轮询顺序、多弹种配额、计数器边沿和残骸队列。schema 2 迁移保留普通/寒冰库存与原配额，新增物料和计数从中性状态开始。schema 1 的 5×12 数据同时迁移当前状态和死亡检查点，按原坐标重映射电线；旧厂买到的第 11/12 列保留。镜头位置只是当前视图状态，不写入经营档。

机器等级随工厂格保存，射手与投手等级由原生 `Shooter` / `MelonPult` 的 `SaveExtraData/LoadExtraData` 保存。旧档缺少等级时按一级恢复；非法等级或尚未开放的等级会拒绝加载。死亡继续恢复开波时的等级与投入，该波中途的升级也随检查点一起回退。

## 实现与验证入口

- `PlantVsZombies/Game/Workshop/Workshop.h/.cpp`：Board 独占的工厂值对象；机器定义、费用、解锁、容量、生产与生成排期集中在此。它不模拟植物、僵尸或弹丸。
- `PlantVsZombies/Game/Board/BoardWorkshop.cpp`：真实战斗的接入、工坊出怪组成、清波、补种、基地越线伤害、前线与工厂的组合存档。普通 Board 没有工坊子域，既有冒险流程保持原样。
- `PlantVsZombies/Game/WorkshopScene.h/.cpp`：输入、原版素材复用、状态提示、保存与死亡选择。工厂使用独立相机，绘制、点击和信号线共用世界坐标与变换；自绘庭院只作背景，不赋予隐藏地形规则。原生战场维持原五行草坪，不新增 Board 背景枚举。
- `PlantVsZombies/Game/MainMenuScene.cpp`：原版按钮皮肤的独立入口。
- `tests/WorkshopTests.cpp` / CTest `workshop`：资源守恒、单拍运输、生成提交、电路与记忆、工厂存档恢复及坏档事务性拒绝；真实战斗由可见 AutoTest 验证。
- `autotest/scripts/smoke_workshop.json`：真实主菜单/建造/弹窗点击、前线战斗、解锁扩建、继续经营、取消重置与确认重置，以及同步截图。AutoTest 只访问当前脚本输出目录的 `workshop.json`，同进程可从菜单继续测试基地；新测试进程不读取上次遗留档。
- `python autotest/verify_workshop.py`：比较可见测试的存读档完整投影、失败恢复结果以及冒险关卡/植物解锁前后不变，核实截图产物存在。
- `smoke_workshop_upgrades.json` / `verify_workshop_upgrades.py`：实际升级按钮、单体等级与费用、旧档、缺钱/满级拒绝、退款、真实射速与耗弹、前摇中升级后恢复、被吃掉后重建及败局检查点。`workshop_snapshot` 只在 AutoTest 内使用脚本隔离文件构造边界，不暴露玩家改资源入口。

物流使用同一节拍的库存快照，每颗弹药每拍至多跨一格；所有目标先预留容量再提交。电路读取上一拍信号，反馈环不递归求值。射手前摇提交时预留一颗弹药，发弹继续使用既有动画事件；预留后的射手被杀会损失该颗弹药。工坊不新加动画帧事件，生产和信号按工厂节拍推进。工坊文档的 `battle` 与 `battleCheckpoint` 复用正式关卡序列化，恢复前摇和在途弹丸不会再次收费或重发。

新地图原图与生成提示见 `docs/art/workshop-garden-prompt.txt`。`smoke_workshop_cold_map.json` / `verify_workshop_cold_map.py` 验证四角与中心点击、鼠标锚定缩放、中键拖动、扩建、类型供弹、真实寒冰命中、阴影、前摇与混合库存恢复。

`smoke_workshop_catalog.json` / `verify_workshop_catalog.py` 覆盖真实卡片和分类点击、锁定及不足额提示、预览与连续扣费、最近选择去重、打开时冻结完整快照、手动暂停/倍速恢复，以及反复开关后控件数量不增长。图册外观入口在 `WorkshopSceneCatalog.cpp`，`World::CanBuild` 与 `Build` 共用资格检查。

`WorkshopSceneInteraction.cpp` 集中管理工具状态、左键点击/拖动仲裁、悬停旋转与操作反馈。`smoke_workshop_interaction.json` / `verify_workshop_interaction.py` 用正式鼠标长按、移动、松开和快捷键验证三种工具下拖图不施工、Esc/右键取消、悬停旋转、单次/连续拆除、接线阶段和暂停镜头；拖图前后比较完整基地快照。

`WorkshopSceneFrontline.cpp` 管理前线图册、按格种植/铲除、能力操作和五弹种配额面板。纯逻辑 `workshop` 测试补充多弹种流转、残骸守恒与每波上限、计数器边沿、schema 2 迁移和新威胁登场；后期战斗平衡不在图册 UI 专项的覆盖范围内。

`smoke_workshop_guide.json` / `verify_workshop_guide.py` 通过可见窗口验证锁定卡片、图解按钮、目录翻页、嵌套弹窗返回、同波解锁批次、阅读进度存读档、旧档不补弹及控件回收，并比较查看指南前后的完整战斗快照与恢复后的推进。对应截图覆盖物料链、电路端口、植物供弹及防御摆法。
