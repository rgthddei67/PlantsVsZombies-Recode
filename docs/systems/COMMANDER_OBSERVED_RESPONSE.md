# 指挥官：公开反应与未付款分阶段规划

本模块根据本局已经发生的公开反应，给有限的试攻提供第二份完整预测。它不修改兵种、真实钱包、解锁、狙击规则或植物方操作，也不读取 AutoTest 陪练身份、未来脚本或正式随机流。

## 两份世界与真实账本

- 原完整最坏应对世界继续保留，包含原有炮击、留牌、补阵等合法分支
- 行为世界只在已观察的同类局势包络内，延后尚未提交的、直接空格种植的樱桃、辣椒或毁灭菇。免费炮、已承诺攻击、预存植物、铲种和未知工具继续原规则
- 两份世界各自计算同权重、同时域的被动等待基线。排序为两份真实增量的加权和；不能把其中一份收入加进另一份钱包
- `Result.features/score/construction` 保留原最坏世界。期望差额单列 `observedDecision`，原 `ShouldRegroup`、`ShouldConserveCapital` 继续生效

额外采购额度为：可用现金扣48冰恢复储备后的四分之一，与剩余累计风险的一半减全部既有付费活体/队列原成交价，两者取较小非负值。分阶段案的当前兵和整份未付款尾队一起占预测额度。正式付款前使用当前真实账本重新计算，旧分数、标价、额度均不能授权付款。

## 观察与时钟

Board 每0.5游戏秒观察真实可见、屏内、可被攻击的单位，核对卡槽冷却、阳光、冰块和当前合法空落点。只统计每次独立遭遇在2/4/8/16/24秒窗口内的真实未响应；失去可见性或不再合法会删失，而非生成完整容忍样本。

已承诺炮击只覆盖一部分目标时，仍可观察其他目标对应的付费机会。完整可见资本与每张牌的完整最大覆盖资本均保留，另外限制未被承诺攻击覆盖的资本，不能靠剔除目标降低整发灰烬的真实价值。只打已覆盖目标的具体落点不得延期；全部目标已覆盖或缺少可证实几何时不学习。合法来源位负责连续年龄，可学习来源位只控制证据，覆盖变化不能重开计时。真实单位资格与炮/灰烬几何使用明确投影；未知新购资格仍保守处理。

同实体在雾中重现不能重复计票。历史最多保留300游戏秒、64段和8份候选画像。未知特殊能力不迁移；更高集中价值、更紧急威胁、新工具或较少免费就绪炮会恢复原反制。较贵一档或新增经济角色的弱迁移将整份决策权重减半。权重是保守决策参数，不宣称为已校准的真人概率。

每张牌的连续合法机会年龄独立于学习片段。换上下文、已承诺炮击删失、后台重规划都不能重新领取一个H窗口。后台证据代数及正式付款前的精确年龄检查会拒绝过期结果。真实灰烬付款立即撤销旧乐观证据；新局、读档、关闭AI、改变卡组或开发者暂停刷怪会清空暂态观察。

非气象站雾场尚未提供对应公共视野推演时，关闭行为画像支持。未精确投影的斜坡对象Y不使用毁灭菇乐观覆盖。上述边界保留原风险模型。

## 未付款尾队

`FollowupPolicy` 保存构成、相对出生间隔、最早检查和到期，以及可选公开炮击/在途弹清空/就绪炮门槛。推演中未付款单位没有生命、收入或资产；只有同一世界的当前钱足够且名额合法时，才整笔付款并出生。

全案与独立前缀、同尾等待、整队延后共同比较。原条件等待和不要求炮击条件的定时等待都保留；每份策略在两种响应世界中保持同一动作定义。已有旧兵本能诱炮时，不能给多余的新诱饵记收益。

正式执行只在当前首批真实付款后，或完整胜出的单次等待后，记下未付款构成。实际事件只触发新决策，尾队须按当前资格、价格、预算、公开证据和真实棋盘重新评价。已满足条件的尾队优先进入行为候选槽，不保证购买。重复等待不能续到期时间；取消、读档和新局清暂态，已付款队列不受影响。

## 预算和诊断

普通搜索、分阶段搜索和行为比较共用原实时截止。存在可用公开画像及通过整案付款、真实容量和风险额度预检的候选时，普通搜索保留一半预算，剩余时间最多完整比较一个预先轮转候选；任一公平分支未完成则保留既有完整结果。旧后队失格不会被缩小或强买，而是让独立合法候选参评。类型、画像、路线、规模采用嵌套轮转，避免阶段插槽永久漏掉某种合法兵。

AutoTest 的 `commanderObservedRisk:false` 只用于显式消融，仍采集公开历史；正式玩法默认启用。`commander_episode` 支持最多3000游戏秒；后台5倍仍必须为 `batchStepsPerFrame:0` 且实际 DeltaTime 设为5。`screenshotAtSnapshot:true` 可在已配置的单次自然快照处请求实际渲染截图，不暂停陪练或操控采购。

状态与对战记录分别输出当前/捕获历史、逐卡连续年龄、候选构成、完整比较是否完成、两世界差额、额度拒绝、正式提交检查和后队预测账。`robustDelayedWorlds/behaviorDelayedWorlds` 只统计完整反应姿态中是否实际发生延期，便于区分“根本没生效”和“某姿态延期但最坏完整世界仍不变”，不混合不同世界的收益。评估截图/胜负时必须以正式对战记录为准，数值夹具通过不证明能打赢炮阵。

`lastCheckedAt` 是Board最后检查时间，`sampledAt` 是读取画像的时刻，均不是完整Observe流水。现有每秒轨迹不能证明所有半秒样本间上下文连续，不得仅靠来源年龄把不同片段拼成长容忍窗口。

显式 `diagnosticPurchases` 只用于真实付款的固定采购诊断，详见 [诊断契约](../../autotest/COMMANDER_DIAGNOSTIC_PURCHASES.md)。含此字段的对局不能归为自主AI强度结果；默认不会运行它。

## 有界信息试攻

旧的空场计时、三轮试探后大额孤注一掷不再授予采购权限。普通搜索、合法技能或分阶段方案优先；没有正常胜出方案时，信息试攻才比较当前合法能力组成的小额单队。它不假设未知玩家有固定概率放弃反制：完整最坏世界的负收益原样保留，另外在相同长时域中仅撤去尚未承诺的直接付费灰烬，分别与同一支旧军队的等待比较。免费炮、在途炮弹、预存灰烬及其余合法支出仍参与预测。只有真实原始产冰差、未修复的攻击损失或突破能提供物质机会，建造差额与产冰校准倍率不能伪造机会。

单次采购上限同时受64冰、现有现金储备与剩余资本风险约束。整个试验必须完整算完；未算完、已过期、真实当前状态或价格变化、存在未兑现队列均拒绝付款。正式提交重新采样公开局面，重验当前假设、整单成本和当前资本，只在整笔真实成功付款后记账。新购或现有兵含会自动后付冰的能力时不进行这种试验，普通搜索和单位真实规则不变。上限针对本次采购，不能解读为整个正常战斗后续支出的上限。

每局最多保留32类粗情境记录，同时最多一个尚未回本的试验；失败记录不逐出，也不会因狙击获利或读档清零。实际归属波次的工人收入累计回本后，即使老兵仍活也允许重新参评；实际活体和队列仍全价占用原资本风险额度，不因此保留或强制提交新采购。没有回本的记录仍须等真实部队、付费队列及可能返回的事务全部结束才封存为失败，不用超时退款。

同一类永久保留最多64个严格递增的已付波次，波次跨记录唯一；最新一笔付款不能覆盖老工人的收入归因。再次付款追加真实成本，以累计实收和累计成本重新判断是否回本；已经回本的老波仍继续记实收，失败封存后的过期回调则不重新开放资格。钱包装不下的产量、其他波的收入及击杀返冰均不抹去试验损失。全部试验记录的累计成本、累计生产分别封顶100万，任一计数或波历史满额都停止新增试验，不改变真实钱包入账。

关卡存档v31完整保存已付波列表。v30严格校验后只迁移当时已知的最新波，保留累计收支；原机制换最新波前要求全军清空，因此不会猜测仍可能存活的遗漏旧波。损坏的新格式关闭信息试攻，不能借缺字段清空失败历史。该机制允许有上限的真实探索，不保证任何局面都有可安全购买的方案，也不把定时送兵当成持续压力。
