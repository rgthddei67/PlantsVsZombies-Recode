## 状态约定

旧文件未统一登记状态。**没有明确状态的文档视为“历史记录，实施状态待核实”**；文件存在、标题日期、计划勾选均不代表当前代码仍按该方案运行。不要批量把旧文件标为“已实现”。

新增方案或本次实际核实过的旧方案，在标题下使用以下字段：

```text
状态：草案 / 待实现 / 部分实现 / 已实现 / 已被替代 / 已放弃（选择一项）
核实日期：YYYY-MM-DD
当前实现或结果：源码、主题记录或验证证据的相对链接
替代方案：已被替代时填写链接，否则省略
```

“已实现”只表示已按所列日期与证据核实，不承诺后续没有变化。“部分实现”应说明剩余范围；“已被替代”保留原设计正文，并链接替代说明。未经确认的创意使用“草案”，不能直接当成已批准的开发任务。

本轮只建立目录级状态约定，保留历史文件名和路径，避免破坏已有引用。后续实际涉及某份方案时，再结合源码和证据补充其状态。
