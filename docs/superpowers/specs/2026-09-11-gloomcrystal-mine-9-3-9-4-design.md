## 旧僵尸在矿道中的交互

- **普通冰车**：仅从上方直道入口生成，不新增转弯能力。保留碾压、同行冰道及地刺反制，形成上路独有的车辆压力。当前独立水平移动并不代表已通过矿道验收，实现时必须限制正式入口并检查岩壁、种植、冰道与存档行为。
- **普通巨人抛小鬼**：小鬼可以越过岩壁，但不能落在岩壁中。如果预计落点是岩壁，就沿原抛掷方向向巨人一侧回退，选择最近的已连通空地；落地后按普通矿道规则行走。不能通过直接删除小鬼或让它停在岩壁里规避落点适配。
- **极夜钟匠与晶角矿工**：时间锚记录时晶角头盔仍存在，就允许回溯恢复头盔并重新获得冲撞资格；不返还冲撞冷却，也不重放已经结算的冲撞伤害。若回位时正在蓄力或冲撞，取消当前动作并进入完整 6 秒冷却。头盔回溯恢复是下文正常破甲后禁用冲撞的显式例外。
- 钟匠不回滚已经撞伤的植物或已经挖通的岩壁。其他既有僵尸能力仍按各自当前合同运行，新增组合不能静默扩展到未批准的技能重置或地形回滚。

## 幽晶雾潮

### 时机与范围

- 先用于 9-3、9-4。首次在第一面旗帜大波开始时触发；每次 5 游戏秒渐入、50 游戏秒维持、5 游戏秒渐退，共 60 游戏秒。
- 每次完全散去时记当前波为 N，在第 N+5 波开始时再次出现；例如第 11 波散尽，第 16 波再起。剩余波数不足时不再触发。不以清完起雾时那一波作为散雾条件。
- 暂停和倍速照常影响游戏秒。读档恢复阶段、余时和下一次触发进度，不重新计时或重复教学。
- 右侧四列贯穿五行，由右侧洞口涌入；成雾后边界固定，岩壁不截断雾。

### 可见性与交互

- 采用原版式朦胧半遮挡：雾中植物和僵尸仍能辨认轮廓，细节与血量数字变得朦胧。岩壁格界、施工进度、入口预警、卡槽和操作提示清晰。
- 迷雾自身不限制植物索敌、射程或命中；岩壁原有攻击遮挡保持。
- 路灯花不能照亮这种矿雾，三叶草不能吹散；两者其他能力照常。雾潮只按自身事件消退。
- 这项新批准的机制只在适用关卡覆盖首轮矿场合同中的“全图始终清晰可见、不叠加周期灾害”限制；不回改 9-1、9-2。

### 25% 减伤

- 按僵尸脚下逻辑位置判断是否在雾区，不按头部或装备图片边缘判断。进入获得、离开失去，瞬移/换行立即更新资格。
- 所有敌对僵尸均可获得，包括后来出生、召唤、飞行与地下单位；原本不可命中的状态不改变。魅惑后立即失去雾潮保护。
- 满强度承伤倍率 0.75；渐入时减伤由 0% 同步升至 25%，渐退时由 25% 同步降回 0%。没有独立护盾血条。
- 正常扣血伤害均参与，包括直击、溅射、灰烬、持续伤害及魅惑僵尸的攻击。本体与原有防具均受保护，同一份伤害只缩放一次，破甲溢出不再次缩放。
- 复用生存模式词条现有伤害缩放口径：正常伤害四舍五入，正伤害最低为 1；秒杀哨兵不缩放。正常灰烬伤害仍参与减伤。吞噬、小推车等直接处决保持原有结果，原本不能处决的对象仍不能处决。
- 冻结、减速、黄油、打断、磁吸等原有状态与时长不变。
- 雾潮与其他来源减伤独立乘算，不重复叠加自身；例如已有 20% 减伤时，满强度雾潮使最终承伤为 0.8×0.75=0.6。词条本身内部的层数聚合规则不因此改变。
- 表现为贴身淡幽蓝流光、受击短暂亮起、出雾消失。首次提示：“幽晶雾潮：雾中僵尸受到的伤害降低25%，迷雾无法驱散。”

## 回声菇

定位：能承担矿道主力输出的常驻群攻植物，不能只验证会拐弯而忽略真实关卡中的投入收益。作为普通攻击“不沿矿道拐弯”的明确新品种例外，其他植物不自动获得这种能力。

### 基础参数

| 项目 | 已批准值 |
|---|---|
| 解锁 | 9-3 通关奖励，9-4 起可选 |
| 阳光 | 250 |
| 卡片冷却 | 15 游戏秒 |
| 生命 | 300 |
| 占格 | 普通单格植物 |
| 首轮就绪 | 种下或唤醒后 1 游戏秒 |
| 后续攻击周期 | 2 游戏秒 |
| 单轮单目标伤害 | 100；满强度雾潮下为 75 |
| 射程 | 沿矿道最短连通路径 6 格 |
| 声波传播速度 | 每游戏秒 4 格，六格约 1.5 秒 |
| 穿透 | 所有合法目标均承受完整伤害，无目标数量上限 |
| 去重 | 同一轮声波对同一只僵尸最多伤害一次 |

### 矿道传播与伤害

- 从自身向四个相邻方向进入连通矿道，在所有合法分支传播；转弯和穿过敌人不衰减伤害。
- 依据地面连通性，不受僵尸向房屋单向行走限制。自身格是起点，每跨一个相邻格消耗一格射程，转弯照计；以最短连通路程限制范围，分支汇合不重复伤害或无限绕圈。
- 每轮发出时确定路线；在途新挖开的通路从下一轮利用。敌人进入正在经过的声波会受伤，进入已扫过的位置等待下一轮。
- 己方植物不阻挡，岩壁始终阻挡。其他地图的可攻击障碍照常承伤，声波不能直接穿越不可通行地形。
- 非矿场地图改为本行向右六格的全伤穿透声波，伤害与周期不变；矿道拐弯和分流不自动推广到普通地图。
- 命中普通地面僵尸及可受普通攻击的跳跃阶段；不攻击气球等飞行目标、仍在地下的目标或魅惑单位。不附带减速、眩晕、击退。
- 按普通伤害顺序结算防具，不额外绕过铁门等护盾；来源归回声菇，既有来源免疫、受击免伤次数等照常生效。

### 生命周期与表现

- 有可命中目标才发动，空闲保持就绪；攻速词条缩短周期而不降低单轮伤害。
- 沿用蘑菇白天睡眠、咖啡豆唤醒规则，矿场保持清醒；可套南瓜、用搬搬藤搬运。
- 在途声波独立传播，来源搬运或死亡不撤回。搬运保留攻击冷却，下一轮从新位置发出。
- 读档恢复冷却和在途声波，保留本轮命中记录，不重新伤害已命中目标。
- 外形采用同心纹路菌盖、发声时张开的菌褶、沿地面推进的弧形声纹；声音短促低沉，避免密植后持续刺耳。
- 优先复用现有蘑菇攻击动画与已有事件。资产与时间轴尚未核实；若确需新增帧事件，必须先提出具体帧号让主人批准，本设计批准不替代该批准。

## 晶角矿工僵尸

定位：9-3 首次登场的重型矿工，利用岩壁与转角接近植物，在清晰蓄力后进行直线冲撞。主人批准完整提案，并将最大冲撞距离从两格调整为六格、单次伤害从 300 调整为 500；触发距离仍为前方两格，不能混为同一个参数。

### 基础参数与投放

| 项目 | 已批准值 |
|---|---|
| 本体生命 | 1000 |
| 晶角头盔生命 | 1000，一类防具 |
| 普通移动 | 基础僵尸步行速度 |
| 普通啃食 | 基础僵尸啃食强度的两倍 |
| 触发距离 | 当前前进方向两格内有植物，且中间是连续直通矿道 |
| 蓄力 | 1.2 游戏秒，停步低头、晶角发亮 |
| 冲撞速度 | 普通步行速度的三倍 |
| 最大冲撞距离 | 6 格；这是行进上限，不扩大触发距离 |
| 冲撞伤害 | 500，命中第一株可攻击植物的当前战斗顶层 |
| 冲撞后冷却 | 6 游戏秒 |
| 教学 | 9-3 第 3 波，上入口保底一只并配两只普通僵尸；先扣预算、不足补足本次组合 |
| 预算成本 / 随机权重 | 3000 / 3000 |
| 后续投放 | 教学后进入 9-3 随机池，9-4 继续投放 |
| 数量限制 | 每波累计最多一只、场上同时最多两只；不另设整关累计上限 |

### 冲撞行为

- 支持横向与竖向直线冲撞，不隔墙锁定，不在冲撞过程中拐弯；六格仍受连续可通行直线段约束，不能穿越岩壁或棋盘边界。
- 蓄力时锁定方向与最远终点，不追踪被搬走的植物。途中其他植物可以接住冲撞；目标已搬走且途中无阻挡时，行进到终点后停下。
- 撞到第一株可攻击植物时只结算一次 500 伤害并立即停止；有南瓜时先伤南瓜，不同时击伤全格各层或继续碾过整排。命中后的后续普通啃食仍按既有战斗层级重新选目标。
- 命中或落空后进入 6 秒冷却，期间正常行走与啃食；冷却结束后可再次冲撞面前尚未被吃掉的植物。
- 硬控暂停蓄力或冲撞，减速照常影响行动。警铃花只能取消尚未冲出的蓄力，使其进入 6 秒冷却；开始冲撞后不再接受这项未提交动作取消。

### 防具、控制与生命周期

- 晶角头盔属于矿晶，不能磁吸；正常破甲后失去冲撞，不能自行重新长出头盔，冲撞途中破甲立即停止。钟匠可按上文时间锚规则恢复当时仍存在的头盔与冲撞资格，但不退款冷却或重放伤害。
- 断臂仍可冲撞；断头、死亡或魅惑立即取消。魅惑后保留普通战斗能力，停止使用冲撞。
- 普通伤害和灰烬照常结算，雾内享受雾潮 25% 减伤；允许正常吞噬、小推车处决，不增加额外抗性。
- 非矿场地图可向前进行同行冲撞。存档恢复防具、阶段、蓄力/冷却余时、冲撞终点与已结算状态，不重置能力或重复命中。
- 重型矿工形象突出前伸晶角，头盔有完整、开裂与碎裂表现；蓄力动作和声音应能穿过薄雾被辨认。断头时头盔随头一起飞。
- 优先复用已有动画。确需新增帧事件时，仍须提出具体帧号让主人批准。
