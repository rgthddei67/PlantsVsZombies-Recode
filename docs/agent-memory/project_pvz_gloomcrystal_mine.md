## 已批准合同（设计，不是实现或验证证据）

- 五行九列平地；暖灯旧矿场与幽蓝晶洞，木支架、矿土。精致成套背景、岩壁、转角、断面和施工位图，禁止占位方块交付。遮挡单位的前景岩体局部淡化，底座和格界仍清楚。
- 地下无天降阳光、蘑菇清醒；不叠加周期灾害、随机封路。全图地形与单位始终可见，暗色只作氛围。
- 每关固定初始布局；右侧固定入口有天然矿道通向房屋，开凿不增加入口。9-1两个入口，天然路线不合成唯一通道；后续入口按实际路线作用设计，不按数量递增难度，出怪预算独立。每波提前标亮使用的入口，不显示数量与完整阵容。
- 普通僵尸沿已连通格向左/上/下走，不向右、不斜穿。按合法有向图计算至房屋最短剩余格数，每步严格下降以防循环；并列优先向左，否则每只僵尸固定上下偏好并入档。开凿后先走完当前边，再到格子决策点重选。植物/减速/拥挤不计入路程，僵尸可重叠通过。
- 连续换行，按实际位置受击，越过行中线更新索敌行与排序。竖向遇植物照常停下啃，不穿过、不绕开，施工重算不取消正在啃食。
- 左侧两列永久无岩壁，进入后只向左；五辆推车各守一路，直冲遇墙停止并消耗，不转弯不破墙。
- 棋盘内岩壁全可挖，外围洞壁不可破坏。目标须四邻接房屋侧已连通地面，不可隔墙/对角施工。孤立空地不可种植；挖通后直接种植，不需承载。
- 统一75阳光/8游戏秒，暂停/倍速同步，全场同时一处，无队列、次数上限或涨价。开始扣费，完工前可取消全额退款且进度归零；完工永久改变地形不可撤销。普通僵尸不打断施工，不生成可攻击工人；完工前完整阻挡。
- 镐子与铲子并列、不占卡位；可挖格高亮，先点击预览费用/工期/新旧路线，再确认；右键退出。主人后续明确改为镐子与矿道图两个新按钮仅正式 GAME 后显示并接受点击；选卡阶段不提供工具入口。战斗中可开关路线显示，不暂停，包含全部等长分支与变化路段。
- 攻击保持原方式，不沿矿道拐弯。岩壁阻挡直射/抛射/局部爆炸，普通攻击不破墙；真正全场能力不受阻。发出位置到目标直线穿岩格或擦过对角公共点均算阻挡，自动索敌跳过遮挡目标。抛射离手锁落点、不追换行。种植悬停展示原范围与遮挡暗区。
- 施工有裂纹加深、碎石和最终岩体碎落，进度条仅辅助；完工同步更新相邻断面/地面/逻辑。
- 读档恢复地形、施工与行进状态；重试或下一关恢复该关初始布局和阳光，不跨关继承。
- 9-1暂定200初始阳光，初始空间足够不开凿起步；守完波次即可通关，不强制挖墙。提供一块可选教学岩壁，增加空间/射界并缩短敌人路线，首次选择提示交换；不放新开凿僵尸。9-2新品种由另一个任务实现。
