## 雾潮

- `BoardMineFog.cpp` 独立状态只对75/76生效。第10波首次，5秒渐入+50秒维持+5秒渐退；完全散尽时按当前波N登记N+5。已过游戏秒、下一波与首次提示入档。
- 逻辑右四列敌对僵尸满强度25%数值减伤，渐入/退同步；魅惑、离域立即失效。`Zombie::TakeDamage` 分层前缩放一次，灰烬致死预判同入口。`ScaleNumericDamage` 复用生存词条的四舍五入、最小正伤害与秒杀哨兵。
- 不接入普通雾的索敌遮挡、照明和驱散。普通雾片独立错位叠层，覆盖岩壁，右侧延伸到画面边缘，避免最右格硬截断。HUD在世界雾之后；贴身流光消费即时资格，不另存护盾。

## 回声菇

- `EchoShroom : FumeShroom`：250阳光、15秒卡冷却、300生命；复用已有27号发射事件的虚入口，未新增帧事件。首轮准备1秒，2秒攻击周期；无目标保持就绪，攻速/睡眠/咖啡沿用正式入口。
- `BoardEchoWave.cpp` 持有在途攻击：发射冻结六步最短路，四格/秒；矿场四邻接通路，其他地图同行向右。每轮每目标100伤，各分支全额，汇合用稳定ID去重；不绕过普通防具，来源为回声菇。
- 来源死亡/移动不撤回声波，开墙只影响后续发射。路线、前沿、已命中ID与唯一冰墙命中标志入档；种植预览共用 `BuildEchoWave`。
- 独立蓝色环纹菌盖，经典身体、眼部、喷口和尖端为有意复用。卡图共享菌盖母图，生成器锁定源图/参考/输出哈希，注册键由专项断言。
- 卡图在 `Card::DrawPlantImage` 中按图片区等比缩小并居中，避开边框与价格；顶部卡槽、完全展开的选卡面板和奖励页均已截图确认。
- 同帧铲除后保存暴露旧残壳问题：序列化跳过已失活植物，避免注册表延迟移除期间保存并复活旧壳；仍活动的压扁/冰封对象正常保存。

## 晶角矿工

- 本体1000、非磁性一类晶角1000，普通移动、双倍普通啃食。当前方向两格内有可食顶层则锁直线，1.2秒蓄力后以三倍速度冲撞，最多六格，岩壁/边界裁剪；首株顶层500一次伤害，完成/落空6秒冷却。
- 搬走目标不追踪，后来进入路径的植物可拦截。硬控暂停动作、减速影响推进；警铃草只取消蓄力，冲出后不可打断。破甲/断头/死亡/魅惑取消，存档恢复方向/终点/速度/冷却，异常活动状态转冷却。
- 头盔为 `anim_head1` 命名 follower，缩放0.72，完整/裂损/碎裂并随头脱落；脱落粒子缩放0.6。低头时主头、下巴、舌头、头发四个独立世界轨一起小幅偏移，退出/读档一起还原。
- 时间锚可恢复快照头盔，不回放冲撞或伤害。存活者动作中回位进入完整冷却；复建替身经 `OnTemporalRecreated` 进入完整冷却，避免默认READY退款。存活者既有冷却保留。
