# 第八大关适应头盔僵尸与植物伤害来源

## 玩法合同

2026-08-28 已实现 `ZOMBIE_ADAPTIVE_HELMET`：普通僵尸时间线、800 本体和 100 点不可磁吸金属头盔，且不可魅惑。最终缩放伤害大于等于当前头盔生命时，整击只击碎头盔并写入唯一适应槽，不向本体溢出；以后不替换适应。基础植物与对应紫卡双向归入同一谱系，真正灰烬植物归入共享 `ASH`；倭瓜等非灰烬秒杀仍属于自身谱系。数值伤害免疫不清除减速、黄油或毒层，持续毒伤归毒囊射手谱系；只有大嘴花吞咽和小推车沿既有直杀链绕过。

头盔是 `anim_head1` 命名 follower，按比原头图更大的透明画布使用 0.82 倍并向左/上回中；适应后隐藏头盔并在 `Zombie_body` 显示不透露具体来源的冷蓝胸章。胸章在断头后仍存在，死亡才隐藏。两个 PNG 均在权威 `build/clang-release/resources/image/reanim/`，由 `resources.xml` 和 `ResourceKeys.h` 注册。

## 来源与存档

`PlantDamageOrigin` 只有 `NONE/PLANT_LINEAGE/ASH`。所有植物弹丸从 `Board::CreatePlantBullet` 锁定原发射植物；火炬只改 `mBulletType`，不改来源。直伤、范围伤、寒冰菇固定伤害、倭瓜和毒伤在提交边沿显式传来源。Bullet 对象池复位清空来源，在途存档恢复来源；目标通过 `BlocksPlantDamage` 和 `TryAdaptHelmetToPlantDamage` 窄虚接口消费。关卡 schema v9 为旧档补本波生成预算、8-3 教学投放标志和旧弹丸无来源单位元；僵尸自身用 `SaveExtraData/LoadExtraData` 原子恢复适应槽、头盔与胸章。

2026-08-30 为钟匠时间锚加入专属 `ZombieTemporalAbilityState`：`NONE`、共享 `ASH` 与全部植物谱系均编码进目标自解释的 `phase`，其中 `NONE` 也必须作为有效快照，才能撤销锚定后新获得的免疫。结算先恢复核心防具，再原子对齐适应槽、头盔互斥状态和两个 follower；目标期间死亡时可随同稳定 ID 重建恢复原来源。活动锚存档沿用 schema 12 的既有字段，仅把读取上限从祭司/钟匠的小阶段枚举扩到完整植物谱系编码；旧档缺能力快照时保持旧兼容语义，不猜测历史适应状态。

## 投放与验证

内部 66（8-3）在首次必定白毛风结束后独立保底一只；自然候选在此之前拒绝，登场后每波最多 4 只。内部 67（8-4）及之后生存池同样每波最多 4 只；两关都不设场上同时或全关累计上限。当前初版 8-3 池为 `[0,1,3,5,17,47,48]`、300 阳光/30 波；8-4 为 `[0,1,3,8,13,29,31,47,48]`、400 阳光/30 波，主人后续可微调旧僵尸组合。

专项 `smoke_adaptive_helmet_zombie.json` 覆盖差一血耐久快照、等血击穿、无溢出、西瓜与冰瓜谱系、灰烬共享键、倭瓜自身谱系、状态保留、毒层持续伤害、不可魅惑/磁吸、大嘴花/小推车绕过、火炬转换和在途快照、适应后僵尸与 Board 快照、8-3 白毛风后保底，以及 8-3/8-4 每波 4 只且无同时或累计上限；截图验收头盔回中、胸章和八只跨波同场。`smoke_clockmaker_adaptive_helmet.json` 另锁定锚后适应回退到精确 40 点头盔、锚前曙光莲谱系及 `ASH` 在中途存档和死亡重建后恢复、免疫实际生效与 `mZombieNumber` 不漂移。
