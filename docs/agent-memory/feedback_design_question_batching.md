# 设计问题集中询问

2026-09-11 主人在 9-3～9-4 与回声菇设计讨论中明确要求：把“一次性把全部问题问出来”写入记忆和 skill，后续按此执行。

- 同一个植物、僵尸或机制先核对既有决定，再把当前可预见的全部待定玩法问题放在一条编号清单里，每项给出建议；允许主人回复“全部按建议”或只修改部分编号。
- 不再默认每轮只问一个、确认后又挤出下一个问题。此前矿场“一次只讨论一项”的旧偏好不能继续解释成逐轮单问；可以聚焦同一主题，但该主题的问题应集中问齐。
- 已批准内容不重问；主人明确“未提及的全同意”时，按其回答保留其他建议。仅对回答产生的新分支或新发现的实质冲突补问，不能以集中提问为由擅自补全未批准规格。
- 主人当次明确要求“只问一个”时仍优先遵从。新增动画帧事件等既有审批边界保持不变。
- 这条记录只改变讨论流程，不代表已实现或验证当前讨论的地图、雾潮或回声菇。
