# 戴夫工坊委托与奖励扩展

2026-11-07 已落地的设计记录。数值为本轮确认值，后续调整以源码为准；运行与验证入口见[戴夫工坊](../systems/WORKSHOP.md#戴夫委托与专属奖励)。

## 已确认

- 任务板由玩家主动接取，每批六项，简单/中等/困难各两项；同时最多接两项，从接取后计进度，可主动放弃，完成后手动领奖且不可重复领。
- 每十分钟袭击模拟时间刷新未接任务；随倍速推进，准备、暂停和离线不计时，保存剩余时间。已接任务不随刷新消失。
- 简单/中等/困难期限分别为五/八/十二分钟袭击时间。达标后停止倒计时，领奖可延后；超时只失去该项奖励。
- 普通奖励为按阶段和难度增长的阳光。特殊奖励为指定蓝图加一份成品/免费使用机会，接取前展示。蓝图仅当前基地有效，重建重新获得。
- 蓝图纯随机，无保底或连续未出补偿。简单概率为零，中等每条百分之五；困难每条百分之二十五。已接/已获得的同款蓝图不重复出现，没有符合阶段的蓝图时提供阳光奖励。
- 重装机枪射手：守住第十波后进入蓝图池；普通射手原位改造，继承等级和血量比例；一次免费改造，之后每次六百阳光。四连发，每发普通豌豆两倍伤害，额外贯穿一个目标且后者伤害为百分之五十；每轮先预留四颗普通弹，不足不开火。三级攻击间隔为 1.5/1.2/0.9 秒。部署仅受前线格位限制。
- 炽焰树桩是独立任务奖励，不与机枪打包。守住第十四波后进入蓝图池，一次免费种植，之后每株三百五十阳光。普通豌豆及重装弹当前伤害乘三，同颗弹只增幅一次；保留重装穿透及第二目标的百分之五十系数，寒冰沿用先融冰规则。
- 教程只自动提示一次，记录属于玩家，不随基地重建/重试清空；教程书和练习可主动重看，新解锁内容仍可首次提醒。

- 高压育豆机：守住第六波后进入蓝图池、同级三倍产能/两倍耗电、单位豌豆阳光不变、二百造价、三级升级、附送一台、数量仅限格位。
- 后期出怪：第十一波撑杆、十六波扶梯、二十波投篮、二十四波跳跳、二十八波精英撑杆、三十波精英投篮，与现有重型单位交错。首发波保证出现新兵种，普通僵尸持续保留，其余从已开放池抽取，本波结果保存不重抽。

## 实现边界

- 正式工坊继续使用唯一 Board、原生植物/僵尸和弹丸，不另建战斗模拟。所有奖励、倒计时、随机结果和已消费免费机会必须保存，读档不重抽或重复领取。
- 复用既有四连发动画事件；本轮未授权新增帧事件。新植物外观及连续发射需可见验证，资源键必须真实注册。
- 工坊模型、玩家提示记录和 UI 各自保持清晰所有权；任务奖励不可影响普通冒险。

任务规则与蓝图阶段位于 [`WorkshopCommissions.h/.cpp`](../../PlantVsZombies/Game/Workshop/WorkshopCommissions.h)，产能/火力参数位于 [`Workshop.h`](../../PlantVsZombies/Game/Workshop/Workshop.h)，植物资格与僵尸池位于 [`WorkshopRoster.h`](../../PlantVsZombies/Game/Workshop/WorkshopRoster.h)。四连发数量必须与 `GatlingPea` 既有四个动画事件一起维护，源码断言防止只改预留数。
