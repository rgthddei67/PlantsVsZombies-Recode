# 伤害、防具与剥离

按当前任务读取命中段落，各专项只在对应机制受影响时适用；流程与审批遵循 [技能入口](../SKILL.md) 和 [AGENTS.md](../../../../AGENTS.md)。

### 灰烬致死若要求直接消失，不能只改 `CanBeCharred()`

覆写 `TakePlantAshDamage()`，按词条缩放后的最终伤害与“本体 + 当前额外生命层”判断是否确实致死；致死直接 `Die()`，非致死继续 `TakeDamage(..., PLANT_ASH)`。同时覆写 `Charred()` 收口其他兼容调用，避免落地态仍生成烧焦残影。带额外生命层时不要简单放开飞行态 `CanBeCharred()`，因为通用调用方多只比较 `mBodyHealth`，会把本应剩血的目标误删。AutoTest 至少分别覆盖额外层仍在与落地后两态，并断言实体、`charredZombieCount` 和特殊爆裂音效。
### 高生命首领不能只提高 `mBodyHealth`

逐项审计绕过数值耐久的统一入口。土豆雷会向 `TakePlantAshDamage(INT32_MAX)` 传直杀值，若需限制单次灰烬，应在该虚入口先压回基础上限再调用基类，以保留植物词条缩放。大嘴花的 `TakePlantInstantKill()` 只返回是否确实吞下；拒吞时由大嘴花把默认 20 点交给 `AdjustRejectedChomperBiteDamage()`，再走正式 `PLANT` 伤害链。未来拒吞品种默认不覆写调整入口；只有已有明确特殊数值的品种才覆写，不能让每个普通拒吞目标各自复制 20。巨人、红眼巨人和屋脊督军均拒吞并使用默认 20；持杆跳跳因高度咬不到，按装备状态将拒吞伤害调整为 0，失去弹跳器后恢复基类吞食。另按设计覆写 `CanBeCharmed()`、`ResistsTangleKelpDrowning()` 与 `CanBeKilledByMower()`；小推车免疫只跳过处决，车辆仍须正常启动、消耗并驶离。专项必须用真实植物/车辆覆盖每条入口，并以普通僵尸对照锁定默认直杀行为，同时回归已有特殊拒吞伤害。

### 车辆/精英变体的特殊受击

让车辆基类拥有虚事件（如 `HandleCaltropHit`），植物只命中并派发；普通车辆在默认实现里处理植物消耗、音画和死亡，精英车辆覆写生存规则，避免植物侧 `dynamic_cast` 到每个精英类型。若特殊死亡播放的是 wheelie/bounce 等非通用 `anim_death` 轨道，不要设置会被基类死亡轨看门狗消费的通用 dying 标志；用独立状态+计时器守卫 `ZombieMove`、碾压和继续承伤，存档保存状态/剩余时间，Load 和 `ZombieItemUpdate` 重新应用停驶、碰撞禁用及材质终态。

### 特定植物攻击抗性

由 `Zombie` 基类提供语义窄的虚修正点，特殊品种按当前防具/状态覆写；子弹只向目标查询，禁止在子弹侧堆类型表或 `dynamic_cast`。若攻击先按倍速累计“每帧总基础伤害”、再拆成多个 `TakeDamage(1)`，目标修正必须发生在累计之前，普通 `AdjustIncomingDamage` 单击上限无法把整帧压低。防具限定抗性在防具掉落后必须返回输入原值，专项同时锁定有/无防具两态。
### 按植物谱系适应或免疫时必须携带显式来源身份

`DamageSource` 和共享 `BulletType` 都不足以表达原发射植物；复用 `PlantDamageOrigin`，弹丸从 `Board::CreatePlantBullet` 在发射边沿锁定 `FromPlant(mPlantType)`，直伤/范围伤/持续伤在能力提交边沿显式传同一值，真正灰烬才传 `Ash()`。目标只通过 `BlocksPlantDamage` / `TryAdaptHelmetToPlantDamage` 等窄接口消费，禁止从弹型、贴图、粒子或内部 `DamageSource::PLANT_ASH` 猜玩家语义。火炬树桩等运行时转换只改变当前弹型与命中语义，来源仍属于原发射植物；来源必须随在途存档恢复，并在对象池 `Reset()` 归零。基础/紫卡谱系、跨植物类别、状态是否保留仍按主人逐项定案；专项至少覆盖转换前后来源不变、在途快照、池槽复用，以及数值免疫后状态的独立结果。
### 防具伤害倍率与溢出必须使用同一原始伤害口径

若湿润等状态只放大一类防具承伤，覆写来源感知的防具入口，并返回“未被防具消费的原始伤害”，不能把倍率后的负生命直接溢出本体。固定环境伤害若规格要求只碎甲，则把输入截断到当前防具生命并禁止溢出；专项至少覆盖差一血破甲、本体不受固定伤、普通植物破甲后按原始余量进本体和小数余量存档。
### 独立破层值由目标当前层消费且禁止溢出

盐蚀、破冰等不属于普通直击伤害的数值由 `Zombie` 语义窄虚入口接收，默认目标 no-op；拥有冰制护甲/墙体的品种只扣当前冰层并在零处截断，余量不得换算成本体伤害，弹丸侧也不得维护品种表。普通直击仍走原伤害链，两者在 AutoTest 分别导出并断言。主动干扰寒潮预报的品种只在正式动作提交边沿调用 Board 的单一干扰入口，由 Board 通知植物并保存本轮失效态；僵尸不扫描植物、不清空空中弹，也不复制预报计时。
### 可被植物剥离的装备由僵尸拥有契约

在 `Zombie` 提供成对的资格查询与原子剥离虚接口，返回当前损伤阶段贴图、装备轨道世界起点和目标偏移，再由品种切到正式无装备 phase/显隐/速度/循环声终态；植物侧禁止识别具体僵尸类型。剥离不得调用会喷掉落粒子或触发范围伤害的派生 `HelmDrop/ShieldDrop`，应只复用无副作用的基类层清理并显式重建品种终态。精英或核心能力变体用资格覆写免疫，不在植物侧加黑名单。C# `MagnetItem.mDestOffset` 是未缩放贴图左上角；若植物侧保存的是绘制中心，必须用每张贴图的缩放后半宽/半高换算，不能让所有装备共用固定补偿。AutoTest 覆盖普通/免疫对照、损伤贴图、装备显隐、能力取消、循环声、离体物与双方存档往返。
### 剥离反噬随 `MagneticItem` 一起原子返回

装备若会伤害提取植物，在返回结构中用默认 0 的通用字段表达；磁力菇必须先提交吸取状态和离体物，再直接扣自身本体生命。这样即使反噬致死，目标装备也不会复原；直接扣血是否绕过南瓜/词条由规格明确，不能把反噬伪装成僵尸攻击。专项覆盖第一次精确扣血、充能/离体物存档和下一次吸取致死时第二件装备仍被卸除。
### 僵尸部署且供全体共享的格对象必须归 Board 所有

扶梯、路障式通路等对象用轻量 `GameObject` 表现、`GameObjectManager` 持所有权、Board 持 weak_ptr 并提供唯一格查询/添加/移除接口；绘制锚点从当前 `GetCellCenterPosition/GetCellHeight` 换算，不照抄 C# 800×600 绝对点。共享移动瞬态（攀爬/下落高度、已用列）放在 `Zombie` 基类并入档，特殊移动品种通过现有阶段能力门禁拒绝；撑杆/海豚等自管接触回调必须在起跳判定前先查共享通路。C# 单目标轮询改成多碰撞回调时，停止啃食/能力前必须确认当前动作目标与本次回调对象同实体或同格；已爬过的相邻旧通路只能跳过自身宿主，禁止取消下一格目标并每帧重播走路。对象自身用 Board 可选数组入档，旧档缺字段为空；植物死亡/压扁、行级清除和磁吸等外部生命周期统一调用 Board 接口，禁止各方直接持对象裸指针。原版 `KillAllZombiesInRadius` 对僵尸按像素圆命中，却按爆心所在格的方形 `rowRange` 清扶梯：樱桃/玉米炮为 ±1 格，毁灭菇为 ±3 格；该外部结算必须复用 Board 入口，并分别断言范围内非宿主格清除与范围外保留，避免植物自身死亡清宿主格造成假绿。若格对象附着在可被台风搬运的植物组合上，必须在 Board 逐格事务中与 Cell 同帧换格，并直接消费宿主植物的二维视觉追赶偏移；阻挡留源格，出界/弹坑沿死亡链移除。AutoTest 用显式格对象夹具分别锁定普通单位、特殊起跳单位、相邻两格碰撞重叠期内的目标状态/动画、移除中下落、外部吸取、台风中段零偏移误差和双方快照往返。

### 车辆的场地范围与攻击范围必须分离

多行铺路、速度场或其他地面覆盖由独立入口决定，植物碾压只通过 `CanCrushRow` 等攻击入口决定；禁止从铺路范围推导碾压范围。AutoTest 在同一列的本行和相邻行同时放植物，分别断言压扁状态，再独立断言各行场地状态，防止调整一项时误改另一项。
### 场外地面效果不能夹成边缘占格

冰道世界左缘转列号时保留 `mColumns` 作为未覆盖棋盘的哨兵，不能把上界夹到 `mColumns - 1`。寿命已激活不等于已覆盖格子；普通与黄色冰道用 `extend_ice_trail` 固定左缘，通过正式 `assert_can_plant` 覆盖场外、采样边界两侧与存读档，避免移动时点影响边界断言。
### 手动位移车辆的速度合成

车辆若不用基类走路位移，仍必须让动画与真实 X 位移消费同一组能力、寒冰、雨势、台风倍率；禁止只改 `Animator` 速度。场地增益必须逐因子变换再相乘，不能放大最终乘积；当前鎏金冰道契约为每层把加速倍率乘二（`1.4→2.8`）、减速倍率除二（`0.6→0.3`），中性 `1.0` 不变。重叠场地按仍存活且实际覆盖目标的独立来源逐层变换；进入、离开、来源死亡和范围缩短都要刷新，不能只缓存一个布尔值。若品种能力有最终上限，先保留原始能力因子供统一变换，再在品种覆写的有效能力入口钳位，避免为逆变换叠层而产生无法表达的边界。

### 虚受伤入口可以同步结束宿主生命周期

调用 `TakeDamage`、`TakeProjectileDamage` 或分层受伤虚函数后，不能假定 `this` 仍活动、可选侧车仍存在。投篮车等派生品种会在本体归零时直接 `Die()`，而死亡会立即释放毒素等侧车；调用方若还要更新层数、余量或附件，必须先重查 `IsActive()` 与对应拥有指针。专项用一种立即死亡车辆把生命压到下一次批量伤害可致死，再断言实体与副作用各结算一次且进程不崩溃。
