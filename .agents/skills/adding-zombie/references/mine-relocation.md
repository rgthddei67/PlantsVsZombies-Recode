# 矿道、施工与搬运

按当前任务读取命中段落，各专项只在对应机制受影响时适用；流程与审批遵循 [技能入口](../SKILL.md) 和 [AGENTS.md](../../../../AGENTS.md)。

- 共享地形施工由 Board 原子提交，个体只保存目标/阶段/余时；预留索引从有效个体重建，读档检查目标仍为墙、施工点相邻且可达、无重复预留。取消任务不能清除已经承诺的连续行进边，朝向需按该边同步，避免绕行右移时身体仍面左。玩家与僵尸竞争同墙时只有提交者改变地形，退款也归同一 Board 入口；减速比较同状态余时差，硬控比较余时不变，不能靠等长墙钟推断。

- 开凿选墙由 `BoardExcavator` 采集植物和附近实际兵力，`MineExcavationTactics` 在纯数值矿道上比较真实赶路/施工与不施工基线；这是确定性策略，不受蒙特卡洛开关控制。回声覆盖必须在开墙后重建四邻接传播，不能套用直线模型。植物几何/群伤由 `PlantSimulationProfile` 声明，成长伤害由植物自身 `GetSimulationAttackDps` 投影；稳态走速与锤击由僵尸自身提供，不能在选墙器按品种枚举猜测。无正收益进入既有重试流程，保留工具与已承诺行进边；超额友军只保守采集局部队伍，不能凭空生成未来波次。静态画像与连续 DPS 只作选墙近似，不承诺精确预测玩家临时种植、灰烬、控场或特殊技能；验收同时看瞬间开墙对照和实际工兵完成施工后的战斗。

## 矿道运动兼容

植物主动瞬移前必须通过僵尸自有 `ReleaseRelocatedPlant(plantID)` 解除旧啃食，复用 `StopEatingInvalidPlantTarget` 平衡植物 `mEaterCount`、清目标并恢复走路。不能只移动植物或仅清其计数，否则待提交啃食帧仍可能追伤原 ID；落点接触由正常碰撞重新开吃。专项同时验证旧关系立即终止、随后数秒无远程扣血，以及搬入新僵尸接触区后正常受咬。

幽晶矿场把普通 `ZombieMove` 的既有根运动距离交给 `Board::AdvanceMineZombie`，不能再额外平移一次。返程意图统一由 `UsesMineExitRoute()` 表达，默认跟随 `IsMovingRight()`；新僵尸的满载撤退等同类能力和魅惑都必须在意图改变时立即沿当前路段掉头，不能先走完旧目标格。公共入口比较 `mMineTargetReturning` 并将 `mMineTargetCell` 换成当前边的另一端，水平和竖直路段都不改变当前位置，禁止清目标后从最近格重规划而斜穿岩壁。仅因施工绕行而朝右的品种须像开凿僵尸一样覆写返程意图，不能触发掉头。节点与意图必须一起存档、时间锚捕获和恢复，防止读档重复反转；开凿本身仍保留当前边。实际 Y 越过行中线时通过 `CommitMineRow` 同步行桶与排序。普通敌人用左/上/下有向下降距离；返程单位沿四邻接通路返回右侧入口。新品种的跳跃、钻地、入场等特殊运动不得推定已经兼容此公共步行入口。可见专项应验证中途掉头、竖向换行中线两侧和存读档，不能用纯图测试替代实体运动验收。

矿道中的撑杆起跳要按实际 Y 是否到达行基线判断，不能只比较已经越过中线的 mRow；enter 被拒绝后，stay 必须在持续接触且到行时重试，起跳同时撤销原水平目标节点，落地从新位置规划。解除僵尸能力的地图特判时，同时审计 Board 提交、更新和存档恢复入口；裂隙候选须排除岩壁与未连通地面，时间锚回位须一起保存和恢复连续换行偏移及已承诺节点，禁止把旧节点接到回溯后的新位置。

矿场预抽的正式波次计划在实际出生时仍须经过 `ResolveWaveZombieType`，不能绕过每波累计与场上同时数量上限。9-3/9-4 的冰车只用上方直路入口；小鬼在巨人校正实际投掷原点后锁定合法落点，跨墙飞行与落地后的公共矿道移动分开，落点随在途存档保存。晶角矿工的时间锚只恢复核心数值与头盔，不捕获可退款动作快照；存活且正在蓄力/冲撞时取消为完整冷却，重建替身在 `OnTemporalRecreated` 中进入完整冷却，不能因新实例默认 READY 立即白送冲撞。
