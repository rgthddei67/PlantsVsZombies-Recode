# 动作、啃食与控制状态

按当前任务读取命中段落，各专项只在对应机制受影响时适用；流程与审批遵循 [技能入口](../SKILL.md) 和 [AGENTS.md](../../../../AGENTS.md)。

### 走路权威

reanim 无 `anim_walk2` 必须覆写 `PlayWalkAnimation`（啃完回走/读档全经它）；啃食视觉残留用 `OnStartEating/OnStopEating` 对称钩子；永不覆写 `ResumeWalkAfterEat`。

### 啃食层级必须复刻 C# `CanTargetPlant(Chew)`，不能无条件认物理顶层

`EatingOrder` 的上层只有在自身仍可成为目标时才遮挡下层；倭瓜 `NotOnGround()`、被吊起、压扁或其他 `CanBeEaten=false` 上层都应让同格花盆/睡莲继续成为候选。碰撞回调收到支撑层时，先验证上层的啃食资格再迁移目标；当前目标校验也必须判断“最高有效层”，不能只比较 `GetTopPlantAt` 指针。否则会每帧先判目标失效并恢复走路、随后又从支撑层碰撞重播啃食，表现为动画冻结在同一帧但 X 持续移动。
### 巨人锤击必须逐层派发植物自有反应

命中帧先快照 `overlay/pumpkin/normal/under`，再对仍活动的每层调用 `Plant::ResolveGargantuarSmash()`；禁止在巨人类按植物类型判断。基类默认压扁，正在引爆的樱桃/辣椒/清醒毁灭菇由植物立即走正式爆炸，清醒寒冰菇立即走正式冻结结算并跳过剩余动画；索敌后的倭瓜忽略锤击但保持完整自身动画，睡眠毁灭菇与寒冰菇仍压扁。任一层的忽略或即时结算都不得阻止花盆等其他快照层接收锤击。随机动画倍率下不要靠固定秒数命中；AutoTest 用只推进到既有第 93 帧事件前的夹具，仍让目标快照、植物反应和命中音画走正式路径，并回归读档后的普通压扁与魅惑中断。
### 明确命中整格的逐格威胁必须结算全部植物层

通过 Board 的整格访问入口先快照 `overlay/pumpkin/normal/under`，再让每个仍活动层通过植物语义伤害入口消费同一份本格伤害；通用整格效果可复用 `ForEachActivePlantInCell` 传入动作，带拦截和传播语义的威胁仍应保留窄专用入口，禁止退化成 `GetTopPlantAt` 或“普通层不存在才取顶层”。基础伤害由威胁拥有，植物只返回后续传播语义；接口必须明确多个响应是倍率相乘还是取最强上限，后者用 `min(current, cap)`，不能默认连乘成指数减伤。只在逐格结算伤害时统一取整，禁止在植物侧复制基础伤害或提前整数除法。锚定等传播响应在伤害前选定，使致死当前命中仍能生效，但它改变的传播值只从后续格生效，不能让当前格其他层提前减伤。专项同时断言多提供者组合、响应整数投影和真实后续格扣血，避免只改一侧后假绿。咖啡豆等通常免疫地面伤害的覆盖层若被规格明确纳入，用按冲击类别的窄虚入口声明例外，攻击者侧不得判断植物类型。

### 飞行/落地是命中层状态机，不只是视觉偏移

由僵尸虚接口按当前 phase 声明空中层、地面层或过渡期不可命中，植物索敌与子弹碰撞都查询该接口；高低弹丸的层标记必须随对象池 `Reset()` 归零并入存档。飞行期同时禁用啃食、地面水池状态、冻结/黄油和断肢阈值，落地后再统一补结算；水道气球被击破按原版直接 `Die()`，不能先进入落地动画。飞行额外生命应在基类发光反馈后、普通防具/本体前由虚钩子消费，并参与全局生命倍率。专项至少覆盖空/地弹互斥、爆裂过渡、陆地落地、水道直接消失与存读档。
### 新增完全定身状态要审计全部派生 `Update()`

基类在 `Zombie::Update()` 内早退只能停住基类移动/啃食，派生类在调用返回后仍可能继续倒计时、投掷或开盒。通用短控优先复用 `ApplyParalysis/IsParalyzed`，重复施加取更长余时、写入基类保护字段并统一收敛到 `IsImmobilized()`；永久免疫由 `CanBeParalyzed` 声明，地面危害的飞行/地下命中资格另走 `CanBeAffectedByGroundHazards`，伤害与控制免疫不得混成一个类型表。grep 所有覆写 `Update()` 的品种并在尚未离手的能力门禁前复用 `IsImmobilized` 或明确的 `IsParalyzed`；已经独立离手的攻击应在门禁前继续推进。中立环境麻痹可跨魅惑保留，死亡/掉头转死亡轨和派生直接死亡入口必须先清状态，损坏档不得给永久免疫品种恢复麻痹。专项至少锁定一个带派生倒计时的可定身品种，比较状态生效前后计时不再减少，并覆盖魅惑、死亡、免疫阶段与存读档。

### 不移动阶段

覆写 `ZombieMove` 按状态早退（PaperZombie gasp / 舞王 SNAPPING+HOLD 同款）。
### 入场后才施法的僵尸

在进入停步前摇的入口检查 Board 最右列右缘（格中心加半格宽），使用逻辑位置，不用画面宽度或视觉偏移。准备计时到期但仍在场外时继续走路，不能先进入禁止移动的阶段再等待入场。场外行走加速与施法门禁共用边界查询，动画倍率由当前位置派生并在动画推进前刷新，不另存位置资格；只加速行走时排除啃食、前摇和死亡。专项同时覆盖边界外到期、场外快照往返及场内正常发动；旧能力测试中的场外静止施法夹具须移入场内。某品种解除入场限制时只移除该品种门禁，并同步更新旧专项预期。
### 特殊动作若优先于啃食，必须原子抢占双方状态

进入动作前用基类窄 helper 同帧清 `mIsEating`、植物/僵尸目标 ID、目标植物 `mEaterCount` 并调用 `OnStopEating()`，但不要在 helper 内自动起播走路；调用者随后提交 phase 和指定动作轨。动作期间 `StartEat` 与 `ZombieMove` 都按 phase 早退，不能只让移动停住后继续由碰撞回调开吃。专项先让目标实际处于 `anim_eat`，再发布动作资格，下一帧同时断言目标 ID 为空、`eaterCount=0`、动作轨和原地 phase。
### 一次性动作不能只靠完成分支解锁

放梯、投掷、开盒等阶段若让 `ZombieMove` 早退，必须在断头、死亡、魅惑等使动作失效的边沿原子清理目标/计时并恢复可移动稳态；魅惑后的派生撤销统一覆写 `OnMindControlled()`，该钩子在阵营、碰撞掩码和视觉提交完成后调用。死亡入口要让品种更新对 `mIsDying/mIsDead` 早退，避免旧动作重新覆盖死亡轨；`LoadExtraData` 也要自愈“终止状态 + 未完成动作”或动作 phase 与当前轨道不匹配的旧档组合。否则品种更新会因终止状态早退，移动又因动作阶段早退，形成双重死锁。
### 允许外部工具打断的动作由动作拥有者定义提交边界

只在真正未提交的 phase 通过 `GetInterruptibleSpecialActionRemaining()` 返回非负余时，其他阶段返回负数；`InterruptUncommittedSpecialAction()` 必须在一个入口中撤销半成品对象、清计时/目标、恢复动画，并明确本次能力是可从完整前摇重试还是永久消费。已经离手的弹丸、地裂、公开干扰、完成墙体等独立结果不进入接口。外部植物或工具只按余时和稳定 ID 选唯一目标，禁止知道派生 phase；专项分别覆盖外部中断、自然终止、完成提交与读档修复，防止“状态已回退但半成品残留”或反向回滚已提交结果。

### 啃食中仍施法的派生品种只补一次早退逻辑

`Zombie::Update()` 在通用状态、目标校验和地形同步后会因 `mIsEating` 早退。若规格要求啃食时继续召唤/施法，派生 `Update()` 先记录 `wasEating`、调用基类，再仅在 `wasEating && mIsEating` 且活动、未死亡、未定身、未被水草束缚/大蒜暂停时以同一减速时间基准补调一次 `ZombieUpdate`；若基类本帧已停止啃食，它已经走过正常派生更新，禁止再次调用。施法不得抢占 `anim_eat`，专项同时断言啃食轨道、伤害帧、施法次数与快照往返。
### 跳跃阻拦要拆分职责、动画时序和受伤对象

阻拦植物通过虚接口声明“能挡哪类跳跃”并拥有 Bonk/粒子反馈；接触回调只锁定当前格顶层目标并起播跳跃，必须到 C#/规格给出的动画进度节点才查询一次，禁止一碰植物就提前阻拦。起跳入口必须完整复刻 C#/规格的资格，尤其不能让已经掉头、正在死亡或已失活的僵尸新提交跳跃；无头流血计时不会因跳跃暂停，漏掉 `mHasHead` 会表现成“刚落地就消失”。跳跃一旦合法提交，之后受致命伤应让死亡轨接管而不是回滚动作；落地回调也要拒绝覆盖 `mIsDying/mIsDead/!mIsActive`。阻拦查询不能复用啃食顶层：须按格内层级逐层询问能力，让非阻拦南瓜继续向内找到高坚果；品种跳距超过基类时还要按起跳碰撞框到完整落地碰撞框的扫掠区，沿移动方向选择最先遇到的阻拦者，不能只复查起跳目标 ID，否则会越过后方高坚果。仅按进度检查不需要新增 `AddFrameEvent`；起跳 X、目标 ID、是否已检查和额外根位移须入档，读档恢复原动画帧继续判定，不能直接落地绕过阻拦。跳跃计时必须明确使用真实 delta 还是寒冰后的 scaled delta；若某半程按独立倍率加速，额外根位移必须消费同一时间基准和倍率，且不得把已缩放的 delta 再乘 Animator extra 倍率造成重复减速。被挡时先撤回品种已补的额外位移，再把碰撞框落到实际阻拦者迎敌面，恢复碰撞/阴影、弃杆或落地、切稳态并开始啃食，最后把实际阻拦植物传给派生钩子结算召唤或撞击。**规格写“给 A N 点伤害”先确认 A 是植物还是跳跃者，禁止把碰撞伤害凭感觉记到自身**；常规僵尸对植物伤害走 `Plant::TakeDamage(N, DamageSource::ZOMBIE)` 以统一消费僵尸增伤与植物韧性，只有主人明确要求最终固定扣血才另设不缩放入口。若要求被挡后仍召唤，先创建召唤物再伤害目标。AutoTest 必须同时断言节点前 `JUMPING/anim_jump`、无 Bonk/粒子/扣血，节点后才出现阻拦终态和派生效果，并覆盖“阻拦体外套非阻拦壳”“长跳初始普通植物后还有阻拦体”“接触前掉头不得起跳”和“跳跃中致命伤保持死亡轨”。
### 手动开吃不能依赖碰撞退出收尾

跳跃受阻等状态机可能把僵尸停在植物碰撞箱外的小间隙后直接调用 `StartEat`，这对对象从未进入 `CollisionSystem::currentCollisions`，外力吹离时不会产生 `onTriggerExit`。基类必须逐帧复核已保存的植物目标仍存活、仍是同格顶层且碰撞箱间距仍在允许咬合范围；失效时原子清目标 ID、平衡 `mEaterCount`、调用 `OnStopEating` 并经 `PlayWalkAnimation` 恢复。进入死亡轨道前也要先清啃食状态，`EatTarget` 对垂死者硬早退。AutoTest 同时断言吹离、目标死亡、啃食者死亡三条路径的 `isEating=false`、目标 ID 为空和 `eaterCount=0`。
### 魅惑交互

`StartMindControlled` 非虚，派生类通过 `OnMindControlled()` 接收阵营已经提交完成的单次回调；正在抑制移动的动作在这里原子撤销，禁止继续用 `ZombieUpdate` 边沿布尔量复制钩子语义。魅惑领队后新召唤单位补调 `StartMindControlled()` 继承阵营；若召唤物配置接口会先魅惑再切飞行态，先调用该入口再提交不可魅惑 phase。魅惑者互啃敌方是引擎既有行为，编队混战减员属正常。

### 不掉头的僵尸不要复用普通无头死亡阈值

关闭 `mNeedDropHead/mNeedDropArm` 后，按品种规格在本体真正归零时启动死亡轨；生命仍大于 0 时继续完整行动。任何强制处决入口都应先清空统一可计生命，再交给品种自己的本体伤害/死亡入口接管动作中断、碰撞体和死亡轨；禁止对这类品种无条件调用普通 `ArmDrop/HeadDrop`，否则会混入错误断肢贴图。受伤换图若只由当前生命比例决定，读档直接重建材质，不额外保存易矛盾的伤势阶段字段。专项用处决后专属死亡轨、保留头臂标志和同步截图锁定品种表现。
### 魅惑范围伤害按阵营对称过滤

僵尸自身发起的爆炸或范围伤害若应攻击敌方，统一用 `target->IsMindControlled() != source->IsMindControlled()` 判敌，禁止只在来源已魅惑时跳过魅惑目标，否则未魅惑来源会误伤普通僵尸。AutoTest 的未魅惑与魅惑两侧都同时放普通僵尸、魅惑僵尸和植物，先证明敌方目标实际受击，再断言同阵营与植物是否按设计保留。

### 控制免疫使用基类能力维度，不按品种散落判断

临时免疫通过 `ZombieControlEffect` 位、独立计时与 `GrantControlImmunity()` 发放；派生类的固有免控只覆写永久 mask。所有入口分别守卫 `SLOW/FROZEN/BUTTER/PARALYSIS`，发放时只清除 mask 覆盖的既有状态，计时按游戏时间推进并进入僵尸存档；装备触发后授予的免控属于本体，除非规格明确，否则装备掉落不得提前取消。一次性范围发放在能力结算边沿按稳定 ID 快照，用碰撞箱中心和平方距离复核半径、阵营及活动资格；每个目标独立领取计时，随后离域、来源掉装或死亡不得反向取消。对应蒙特卡洛必须使用预计结算时的位置、相同半径和阵营过滤比较群体收益，不能继续只强化来源自身。寒冰菇的固定伤害、冻结和减速尾巴是三项独立语义：只免冻结时仍受伤且仍减速；黄油弹也应先结算命中伤害，再由 `ApplyButter()` 决定是否定身。`CanBeChilled()` 仍是减速状态、蓝色覆色和减速音效的共同前置总闸；寒冰子弹必须先检查它再播放 `SOUND_COOLDOWNZOMBIE`，避免“没减速却有音效”。蒙特卡洛快照必须同时带入临时余时和永久 mask 的有效结果。AutoTest 覆盖清除既有控制、未免疫类型保留、范围内外与阵营边界、伤害与控制拆分、装备掉落、离域、计时存读档和到期恢复，并用普通僵尸作对照。

### 地下状态与地面能力使用目标拥有的窄接口

普通自动索敌/弹丸资格、地面危害资格和强制出地是三件独立语义，不能只用 `CanBeTargetedByProjectile(false)` 同时代表。地面植物先按 `CanBeAffectedByGroundHazards()` 与 collider 判定实际命中并结算自身伤害，再调用目标的 `ForceSurfaceFromGroundHazard()`；目标自己决定当前阶段是否接受、是否取消自然冲击及是否写入重试时间。接口默认 no-op，调用方不得识别具体僵尸类型或直接改私有 phase。AutoTest 同时覆盖地下弹丸不可锁定、地面命中可触发、强制出地不结算自然冲击，以及满血/已达触发线时不同的重试边界。
### 连续坡面由 Board 统一拥有，品种移动只提交水平语义

屋顶出生、预览、正式行走、阵风横移和读档恢复都以保存的 `row + x` 经 `Board::GetZombieSpawnY`/基类坡面同步重建 Y；气球、矿工等品种不得复制坡度或各自累计 Y。需要地面裁剪、影子或附件落点时查询当前 X 的行地面线。不要给通用 `Transform` 自动套坡面，否则飞行物、UI、独立动画与其他地图都会被误改；专项同时覆盖坡段/平台、预览、读档和至少一个非普通移动品种。

### 小推车特殊交互

若能力只应吞掉“其他行”小推车，当前碰撞车必须先走原版 `Trigger()`，Board 副作用按当前 mower ID 排除它，最后仍按 `CanBeKilledByMower()` 决定是否结算 `INT32_MAX`；不要在全场清理分支提前 return，否则精英会绕过本行最后防线直接进家。AutoTest 把吞车/免疫验证放在新场景，前序编队/动画长等待可能让移动僵尸提前撞到别行 mower，造成断言对象漂移。
### 出土/升起

垂直位移用 `mVisualOffset.y`（存基准值，按计时线性还原）；地面遮挡用现成 `SetClipRect(0,0,SCENE_WIDTH, groundY+margin)`，**底边取 `Board::GetZombieSpawnY(row, currentX)` 当前 X 的行地面线**（换地图与连续坡面自适应），完成后 `ClearClipRect`；升起期不移动不啃食（覆写 StartEat 早退）。出土未完成前通过 `GetShadow()->SetVisible(false)` 隐藏显式阴影附件，并隐藏 reanim 自带 `_ground` 轨道，完整站起后才恢复两者；`ZombieItemUpdate()`/Load 必须重建双层显隐，防 Animator 恢复后 `_ground` 黑影提前出现。AutoTest 导出两者的可见状态并在出土中段、完成节点和读档后分别断言。死亡演出资格不得直接复用“是否已可索敌/啃食”的交互资格：只要升起阶段已经把本体画到地面以上，断头流血或致死伤害就应进入死亡轨，地下移动阶段才可无演出回收；专项用冻结中的无头目标锁定 `isDying + anim_death`、硬控解除和帧事件最终回收。默认让动画继续播放；若主人明确要求静态出土，**只能 `Animator::Pause()` 播放头，不得把 base/extra 速度层写成 0**——后续 `PlayTrack(anim_death)` 会自动恢复 playing，RISING 读档在 `RestoreAnimState` 后须重新 Pause，并必须专项实测升起中死亡不会卡帧。
